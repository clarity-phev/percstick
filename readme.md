Updating firmware from Web Tool (Use Chrome, Edge, Firefox may work (may install plugin))

1. Unplug the battery cable from the microprocessor USB-C input
2. Connect a cable from a USB port on your laptop to the USB-C on the microprocessor
3. Go to this web page – https://clarity-phev.github.io/percstick/
   Select the appropriate firmware and follow steps
4. When done, unplug the USB cable and re-connect the battery
   The PercStick will immediately power on
5. After it boots, connect to the PercStick as usual and verify the correct firmware version on the banner
6. Press and hole the button on the battery until the display dims, then release to turn off the unit
